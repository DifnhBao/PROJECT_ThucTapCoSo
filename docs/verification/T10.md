## Chạy lại

Trong UI chạy `npm test`, `npm run typecheck`, `npm run build` và `npm run lint`.
Lint hiện vẫn exit khác0 do nền cũ. Browser: `npm run test:player:browser` cần
Playwright với Edge đã cài; có thể đặt PLAYWRIGHT_MODULE_PATH tới thư mục module
Playwright ngoài repo, PLAYWRIGHT_CHANNEL mặc định msedge. Harness tự đóng server/
browser; bundle tạm nằm trong .local-backups/t10/browser, không đưa vào app.
Build dùng API_INTERNAL_URL=http://127.0.0.1:5000 trong process kiểm tra.
