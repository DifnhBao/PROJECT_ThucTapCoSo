# T14 — Recommendation correctness và snapshot serving

Hoàn tất trên nhánh `feat/t14-recommendation-snapshots`, ngày 2026-11-01.

## Kết quả triển khai

Node hybrid là engine phục vụ v1. [Contract/config và vận hành](../RECOMMENDATION_ENGINE_VI.md)
quy định signals T11, favorite/rating, repeat cap, eligibility, score/reason và
algorithm version. Python tiếp tục nằm ngoài serving.

Serving đọc active snapshot theo batch, không có fallback TF-IDF hoặc global
behavior matrix trong request. Top-K=50/source, tối đa 20 personal seeds; tie-break
song ID. Cold-start dùng trending public có limit; không có eligible song trả rỗng.
Explicit low rating veto vẫn áp dụng ngoài cửa sổ 200 ratings khi chọn candidates
hoặc trending. Public explanations không chứa raw debug data.

Migration mới tạo runs/state/neighbors và index theo truy vấn. Rebuild CLI có giới
hạn catalog/signals/lyrics, bulk writes, kiểm tra scores/count, transaction và khóa
cross-process NOWAIT. Chỉ commit mới đổi active version; lỗi rollback giữ version
cũ. HTTP rebuild trả 409 maintenance, không chạy đồng bộ. Debug chỉ đọc active
eligible pair, không tính realtime hoặc trả cặp pending.

OpenAPI đã được sinh lại: rebuild không còn khai báo 200 success. Security guide
được cập nhật theo hành vi T14. Legacy similarities không bị xóa/ghi đè.

## Đo query và latency

Xem [bảng số đo](evidence/T14/query-latency.md) và JSON gốc cùng tên. Đo qua actual
Sequelize/MySQL 8.0.46, fixture synthetic 25 và 128 eligible songs, một first-call
và ba warm calls mỗi trường hợp. Không flush buffer pool; first-call không phải
chứng nhận cold database latency. Đếm cả queries batch hydration/relations.

T15 chạy lại shared regression harness đã làm mới `query-latency.json`; bảng Markdown
T14 giữ số đo tại lúc hoàn tất T14. Không dùng hai lượt này làm so sánh trước/sau;
bằng chứng T15 được tách vào evidence/T15 qua RECOMMENDATION_EVIDENCE_DIR.

EXPLAIN có đối chiếu index bật/tắt bằng IGNORE INDEX trên cùng dataset; đây không
phải benchmark latency engine cũ. Index neighbors được dùng cho actual serving;
STRAIGHT_JOIN giữ thứ tự pointer → run → neighbors → source/candidate PK lookup.
Với 20 seeds, EXPLAIN ước lượng 1.000 neighbors; source/candidate lookup theo PK.
Index activity mới khớp user/version/qualified/id; optimizer trên fixture chỉ 2
activities vẫn chọn index user/event hiện có và filesort. Không tuyên bố index này
đã cải thiện latency; cần đo lại khi có dữ liệu đại diện.

## Giới hạn còn lại

Chưa đánh giá Recall/NDCG/coverage hoặc temporal leakage: thuộc T15. Không có
claim Hybrid tốt hơn baseline hay % tăng hiệu năng. Benchmark này quá nhỏ để suy
ra production capacity, chưa là load test hoặc end-to-end browser deployment test.
UI regression dùng bộ type/lint/test/build sẵn có; không gọi media provider thật.

Rebuild vẫn O(N²) với hard cap 500 bài, 20.000 rows mỗi nguồn signal và 10.000 ký tự
lyrics/bài. Snapshot history chưa tự prune; signals/candidate set giới hạn có thể
giảm độ phủ. Bài mới cần rebuild để có similar. Chưa có worker/Redis/online rebuild.
Migration chưa áp dụng lên production; phải migrate và chủ động rebuild khi triển khai.
