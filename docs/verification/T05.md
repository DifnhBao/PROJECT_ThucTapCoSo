## Kết quả triển khai

- Zod4.6.7 kiểm tra params/query/body cho các controller đang được mount:
  auth/users/songs/artists/playlists/ratings/favorites/activity/recommendations.
  Query/ID chỉ nhận decimal string phù hợp; body đúng kiểu, enum/range/length,
  unknown fields bị400 trước business service. Wrapper chỉ ghi dữ liệu đã parse
  vào request; không đổi principal từ JWT hoặc tin userId/role do client gửi.
- AppError dùng code/status/details. AuthorizationError kế thừa AppError, giữ
  các policy đã có. Các service domain errors được đổi ngay tại nơi phát sinh;
  bỏ phân loại theo substring tiếng Việt ở global handler/controllers.
- Global handler phân biệt malformed JSON/URL, media/encoding, size, Multer,
  Sequelize unique/FK/validation và unexpected errors. Lỗi500 không trả nguyên
  văn exception/SQL/stack; request log chỉ có requestId/code/event. Headers đã gửi
  thì delegate. Body204 được bỏ. UUID server trả cùng X-Request-Id và JSON.
- JSON success có `{data,meta}`; data giữ DTO nghiệp vụ hiện có. DTO có trường
  data vẫn giữ field đó; không có heuristic đoán response. Frontend bỏ đúng một
  lớp tại Axios interceptor hoặc readApiResponse. ApiError/Axios response giữ
  status, code, message, requestId và validation details.
- Sửa header admin thành x-auth-type, logout admin không gửi nhầm headers trong
  body, refresh gửi `{}`; login/register lỗi401 không tự gọi refresh. Không làm
  lại rotation/single-flight/cache thuộc T06/T12. Optional duration trống được
  bỏ khỏi FormData thay vì gửi chuỗi không phải số; visibility dùng adminFetch.
- Artist create ghi normalized_name theo quy ước hiện có của song service;
  admin profile clear nullable fields thống nhất với self-profile. Đây là các
  chỗ kiểu input/DTO mới làm lộ sai lệch, không thay role/ownership policy.
- Metadata multipart sai bị chặn trước Cloudinary và file tạm được cleanup;
  không tuyên bố đã xử lý mọi partial failure/MIME sniffing/asset rollback T08.

### Những trường hợp đã kiểm tra

- ID âm/sai hậu tố/vượt signed-int, URL encoding hỏng, limit quá lớn/boolean/
  repeated, q array/object/too long; rating ngoài1–5/sai kiểu; enum/counter/
  số không hữu hạn; email sai định dạng, password byte limit và ngày không hợp lệ.
- Role/identity/created_at injection bị từ chối trước DB/provider/buffering.
  Bổ sung assert valid payload vẫn đi đúng principal, không hạ mức bảo vệ T01.
- JSON hỏng400, sai content-type415, quá lớn413, unknown route404,
  anonymous401, thiếu quyền403 và lỗi500 an toàn. X-Request-Id khớp body,
  không dùng ID client gửi; error message/SQL/password markers không lộ qua
  response hoặc global request log. Late error/204 có tests riêng.
- ORM classes map409/422; MySQL thật kiểm tra playlist duplicate409 và email
  unique409, không tạo thêm account hoặc trả email/SQL. Login/profile dùng
  password synthetic và token thật của backend với envelope mới.
- HTTP server test thực thi Axios/fetch API adapters và artist/song mappers
  thật: auth, playlist, favorites, rating, artist, song list/search/count, admin
  logout body/header và invalid credentials không trigger refresh.
- Bộ T01/T02/T04 vẫn chạy. Test helper cũ chỉ bỏ transport envelope để tiếp tục
  kiểm tra business DTO; contract.test.cjs và các assert MySQL T05 đọc wire JSON
  trực tiếp, không qua helper này. Không dùng mock để suy ra MySQL PASS.
