## Quyết định và thay đổi

Ma trận quyền đã chốt trước khi sửa tại [PERMISSION_MATRIX_VI.md](../PERMISSION_MATRIX_VI.md).

- `req.auth` chỉ chứa `userId`, `role`, `scope`, `sessionId`, được tạo từ JWT đã
  verify, chuẩn hóa userId nguyên dương an toàn và kiểm tra role/scope khớp.
  Không truyền nguyên decoded JWT vào business logic; mọi controller đang dùng
  identity đã chuyển từ `req.user` sang `req.auth`.
- Reset password tách policy `canResetPassword(actor, target)`: admin chỉ reset
  user thường; super_admin reset user/admin; không ai dùng reset cho chính mình
  hoặc target super_admin. So sánh ID thực, có chuẩn hóa; không còn so sánh
  `targetUser.id` với `requester.user_id` đều undefined.
- Thêm `POST /api/users/admin/change-password`, dùng principal và yêu cầu mật
  khẩu hiện tại. UI phân biệt self-change với reset target; self-change gửi
  `oldPassword`, không gửi target ID để chọn actor.
- Rà admin APIs: delete không cho tự xóa/target vượt quyền; create admin chỉ
  super_admin, role mới cố định admin; sửa profile qua admin API chỉ cho target
  user thường. Service promote/demote bỏ hardcoded requester ID 2 và dùng role
  policy; hai routes này vẫn không được bật.
- Recommendation cá nhân chuyển sang `GET /api/recommendations/me`, lấy ID từ
  principal; xóa route `/users/:userId`. Frontend API và caller đổi cùng lượt.
  Tham số userId của component chỉ còn kích hoạt refresh khi đổi tài khoản,
  không đi vào URL API để chọn người dùng.
- Profile `/me` tiếp tục lấy actor từ principal và chỉ cập nhật whitelist trường
  profile. Body chứa `userId`, `user_id`, `role` không thể chọn tài khoản/đổi role.
- Playlist add/remove/delete dùng truy vấn owner-scoped chung với ID được kiểm
  tra. Không có quyền hoặc không tồn tại cùng trả 404 và dừng trước thao tác ghi.
  Controllers truyền lỗi policy sang global handler để trả đúng status.
- Thêm `AuthorizationError` được global handler nhận diện bằng class, trả
  status/code an toàn cho các lỗi T01. Chưa refactor toàn bộ AppError/validation T05.
- Refresh entrypoints kiểm tra identity/scope và gắn token lookup với ID đã ký;
  user refresh từ chối tài khoản không còn role user. Không đổi rotation/revoke,
  schema token hay cơ chế session của T06; không thêm claim sessionId vào token
  đang phát hành để tránh tăng độ dài không cần thiết.

HTTP contract: không có credential/token identity không hợp lệ trả 401;
credential hợp lệ nhưng sai scope/role hoặc sai quyền admin trả 403;
playlist thiếu/khác owner trả 404; target ID sai định dạng trả 400.

## Các ca an toàn đã có assertion

- Principal từ chối ID zero/âm/thập phân/chuỗi lỗi/unsafe integer, role hoặc scope
  không khớp; bỏ claim không nằm trong whitelist.
- Policy matrix theo actor/target roles, self cases và unknown role mặc định deny.
- Admin → super_admin/admin khác, super_admin → super_admin khác hoặc chính mình:
  bị từ chối; không gọi bcrypt hash/save, password fixture không đổi.
- Happy path admin → user, super_admin → user/admin: lưu đúng một lần.
- Đổi mật khẩu chính mình: sai mật khẩu hiện tại không ghi; đúng thì thành công.
- HTTP `/recommendations/me?userId=2` của user 1 chỉ gọi service với ID 1;
  route ID cũ trả 404; anonymous trả 401.
- User không dùng được admin profile route. Profile update body giả identity/role
  vẫn chỉ cập nhật profile của principal và giữ nguyên role.
- Chỉ super_admin tạo được admin; body giả role super_admin không được sử dụng.
- User 1 add/remove/delete playlist không thuộc mình: 404, owner-scoped query,
  không gọi Song lookup, PlaylistSong create/destroy. Owner hợp lệ vẫn thao tác được.
- Refresh sai scope hoặc ID lỗi không query token storage; lookup hợp lệ bao gồm
  signed user ID và access token trả về giữ đúng user scope.
- UI client gọi endpoint recommendation `/me` đúng limit và vẫn áp dụng mapper;
  self-change admin gửi oldPassword tới endpoint riêng, reset target dùng URL target.
