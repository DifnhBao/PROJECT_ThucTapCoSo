# T17 — Responsive và accessibility

Hoàn thành 2026-11-04, nhánh `feat/t17-responsive-accessibility`.

## Thay đổi

- Sidebar/header/main/player dùng biến chiều rộng shell; bỏ content 128% và padding
  bù 300px. Breakpoints đặt trong CSS Modules thật. Mobile dùng nav ngang và player
  gọn; content có khoảng trống cuối cho fixed player. Admin shell có nav/table cuộn
  chủ đích. Player có fallback khi render ngoài shell.
- Tách nút quay lại khỏi vùng tiêu đề, wrap tiêu đề dài, đặt nền chữ ổn định để ảnh
  bìa không giảm tương phản. Tăng tương phản màu chữ muted/brand, placeholder và
  nút tạo playlist; focus ring hai màu, hỗ trợ reduced motion.
- Action phát trong catalog/library/playlist là button có tên; artist action giữ
  callback và busy guard. Player có tên cho like/menu/mute, trạng thái aria-pressed,
  nhãn/giá trị cho sliders; artwork trang trí có alt rỗng và link có tên bài.
- Modal chung, add-to-playlist và create-playlist có dialog semantics, focus ban đầu,
  trap Tab/Shift+Tab, Escape và restore focus. Stack hỗ trợ modal lồng nhau; xử lý
  trường hợp trigger trong popup đã bị unmount. Bỏ autoFocus xung đột trong form.
- Search có placeholder/announcement, giữ điều hướng bàn phím T16. Bỏ nút report
  chưa có hành vi trong player; favorite popup gọi action thật.

## Tái lập và giới hạn

Từ repo root: `npm --prefix UI run check`; khởi động production server bằng
`npm --prefix UI run start -- --port 3016`, rồi `npm --prefix UI run test:accessibility:browser`.
Cần Playwright/Edge; đặt PLAYWRIGHT_MODULE_PATH khi runtime ở ngoài UI. T16_URL đổi
server test. Không chạy build cùng lúc server đang phục vụ bộ browser này.

Browser dùng routes thật và API/media synthetic; player/account suites dùng fixture
và navigation shim như trước. Không dùng provider/database production. Chưa chạy
NVDA/VoiceOver, chứng nhận WCAG toàn site hoặc mọi trang admin ở mọi viewport;
các xác nhận responsive/keyboard ở trên giới hạn trong demo path đã lưu evidence.
Ảnh media trắng là fixture, không phải album artwork thật. Performance/ảnh và 24
no-img-element warnings tiếp tục thuộc T18.

Không commit/push/deploy, không thêm dependency. Server local dùng kiểm tra được
dừng sau hoàn tất. T18 chưa thực hiện.
