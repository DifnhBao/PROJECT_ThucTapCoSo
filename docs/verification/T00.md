## Kết quả bàn giao

1. [Scope portfolio-v1](../PORTFOLIO_V1_SCOPE_VI.md): guest khám phá nhạc;
   user đăng ký/đăng nhập → phát → like → playlist → gợi ý; admin upload/duyệt.
   Following/Daily Mix/comment chưa hoạt động vào danh sách ẩn/làm sau, xử lý
   entrypoint UI ở T16. Kiến trúc giữ Next.js + Express + MySQL + Cloudinary + Node recommendation.
2. `Server/src/app.js` export `createApp()`. Import và tạo app không tự mở port,
   kết nối DB, tạo timer hoặc đăng ký signal shutdown. Giữ routes, middleware,
   CORS allowlist, root response và global error handler hiện có.
3. `Server/src/server.js` sở hữu việc load config trước khi import routes/models,
   authenticate DB trước listen, khởi động timer và shutdown HTTP/timer/DB.
   Import server module cũng không tự boot nhờ `require.main === module`.
4. Controller activity export start/stop timer; bỏ interval và signal handlers
   chạy ngay khi import. Upload middleware chỉ tạo temp directory khi có upload.
   Chưa thay đổi cơ chế buffer/ACK/retry/durability của listening events.
5. Khung `Server/tests/`: unit tests, HTTP API smoke tests qua routes thật,
   test bootstrap chặn dotenv/MySQL/Cloudinary và nhóm integration riêng.
   API tests chỉ tự mở port loopback tạm thời rồi đóng sau test.
6. Khung `UI/tests/`: PlayerService unit test chạy module thật trong Node;
   component tests render PlaylistCover bằng React SSR. Loader TS/TSX chạy trong
   bộ nhớ bằng dependency TypeScript hiện có, dùng ESM và cần Node 22.15+.
7. `Server/config/test-database.js`, `Server/.env.test.example` và integration runner:
   chỉ nhận cấu hình `TEST_DB_*`; không fallback `DB_*`. Runtime DB config và
   migration test config cùng áp dụng guard. `.env.test` thật được gitignore.
8. Không thêm/nâng dependency và không sửa lockfiles. Thêm npm scripts test,
   test theo nhóm và UI typecheck; giữ các quality checks đang thất bại.
