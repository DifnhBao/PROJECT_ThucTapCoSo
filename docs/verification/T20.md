## Phạm vi clone và môi trường

Working tree của repo chính có nhiều thay đổi chưa commit từ các task trước. Agent export source được Git cho phép (bỏ env thực/node_modules/.next/backups), tạo local snapshot repo trong ignored backup, rồi git clone --no-hardlinks sang checkout sạch. Đây là clone của source hiện tại để kiểm chứng build, không phải clone từ remote/release commit chưa tồn tại. Build/runtime không dùng node_modules máy host. Sau bổ sung docs/helper/tests, snapshot/clone được cập nhật và kiểm tra app source tương đương sau chuẩn hóa line endings; shell scripts bắt buộc LF.

Môi trường: Windows/Docker Desktop Linux containers, Node22.19.0, Next16.4.2, MySQL8.0.46, Edge headless. Container artifacts/project chỉ thuộc tunetrek-t20-verification. Lượt CRLF/fixture debugging dùng volume test mới, labels đã kiểm tra trước khi reset; không xóa volume ứng dụng. Giữ volume/backup verification cuối, stop services sau nghiệm thu để giải phóng tài nguyên.
