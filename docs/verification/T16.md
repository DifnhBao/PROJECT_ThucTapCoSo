# T16 — Luồng trang, deep links và UI states

Hoàn tất ngày 2026-11-04 trên nhánh `feat/t16-page-flows`.

## Thay đổi

Tạo song/playlist routes theo ID và legacy song redirect; detail song tải entity
theo URL thay cho currentTrack. Link điều hướng có trong player/search/catalog/
library/playlist. Có thao tác phát bài đang xem, rating/like và owner playlist actions.

Tách ResourceState để phân biệt loading, network error, 401/session expired,
403 và 404/non-public. Bổ sung root/main error boundaries và not-found. Artist list
và admin profile fetch có error/loading/retry; playlist list không coi request lỗi
là danh sách rỗng. Guest đọc catalog/detail không bị tự bật modal đăng nhập.

Search có debounce, AbortController và cleanup flag chống response cũ; loading/
empty/error riêng, clear/retry, điều hướng link bằng bàn phím. Forms có submit guard,
disabled controls và hiển thị field errors theo API contract, giữ input sau server
lỗi. Profile load không ghi đè input đang sửa. Bỏ các control/số liệu giả trên detail,
ẩn menu/tab chưa thực hiện và redirect route Following cũ.

Chi tiết vận hành: [PAGE_FLOWS_VI.md](../PAGE_FLOWS_VI.md).
