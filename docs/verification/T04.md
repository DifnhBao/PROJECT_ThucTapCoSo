  Không sửa credential runtime hoặc chạy vào DB đang dùng.
- Seed transactional, empty-only, repeat từ chối rõ; 5 accounts, 28 songs,
  4 genres, 3 artists, publication matrix, playlists và cold-start fixtures.
  Email/media dùng example.test; password từ env và bcrypt, không nhạc phát thật.
- `db:seed:demo`, `db:seed:test`, compose test riêng, reset helper có guard và
  bộ MySQL integration thực tế. Model activity/playlist khớp schema mới.
