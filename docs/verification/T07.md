# T07 — Rate limits, quota và cookie/origin policy

Ngày26/10/2026. Trạng thái: **VERIFIED trên môi trường test local**.

## Đã thực hiện

- Config tập trung và fail-fast cho origin, trusted proxy, ngưỡng/window quota,
  kích thước request và candidate/rebuild budget. Không thêm dependency.
- Fixed-window limiter trong một instance: API tổng, login IP+account, register,
  refresh, upload theo signed userId, activity, recommendations và rebuild global.
  Store có hard cap, reclaim expired keys và fail closed khi đầy.
- Origin allowlist bắt buộc cho mọi mutation; kiểm tra Fetch Metadata, không tin
  Host/forwarded origin. Cookie SameSite=Lax, HttpOnly, host-only, Path=/; Secure
  production HTTPS. Logout/refresh T06 giữ đúng TTL/revocation và clear options.
- Trusted proxy mặc định off, chỉ nhận IP/CIDR cụ thể; IPv6 IP limiter gom /64.
  Quota không bị bypass bằng route khác chữ hoa hoặc trailing slash.
- Quota upload chạy trước Multer/disk; multipart limits files/fields/parts và activity
  body cap. Metadata fallback lấy candidate có giới hạn; HTTP rebuild luôn có
  limit, cooldown và một tác vụ đang chạy trên instance.
- API security headers không áp CSP lên Next HTML/media/font. 429 có Retry-After,
  thông báo UI và field retryAfterSeconds; không gây automatic retry/refresh loop.
- OpenAPI cập nhật Origin và Retry-After. Hướng dẫn vận hành trong
  [SECURITY_POLICY_VI.md](../SECURITY_POLICY_VI.md).
